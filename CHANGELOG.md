**Зачем:** Команда переименовала проект.

## 2. География: "Кировская область" → "Российская Федерация"

**Где изменилось:**
- Главный заголовок на главной странице — "в Российской Федерации" вместо "в Кировской области"
- Описание в футере

## 3. Проксирование API (Vite → Express)

**Где изменилось:** `client/vite.config.js`

**Что сделано:** Настроен proxy в Vite: все запросы с `/api` автоматически перенаправляются с порта 5173 (клиент) на порт 3000 (сервер). Клиент работает через единый порт 5173.

**Зачем:** Устранена проблема CORS (разные порты), упрощена разработка.

---

## 4. Кнопка "Пропустить" → "Далее" при выборе сувениров

**Где изменилось:** `client/src/pages/Checkout.jsx` — шаг 2 "Брендированные сувениры"

**Что сделано:** Кнопка "Пропустить" переименована в "Далее" для единообразия навигации по шагам бронирования.

## 5. Согласие на обработку персональных данных — кликабельная ссылка

**Где изменилось:** `client/src/pages/Checkout.jsx` — шаг 3 "Подтверждение и оплата"

**Что сделано:**
- Фраза "обработку персональных данных" теперь является гиперссылкой (подчёркнута фиолетовым)
- При клике открывается модальное окно с полным текстом согласия:
  - Цели обработки
  - Перечень собираемых данных
  - Способы обработки
  - Срок действия согласия
  - Права субъекта персональных данных

**Зачем:** Требование законодательства о персональных данных (152-ФЗ).

---

## 6. Календарь с подсветкой дат, в которых есть экскурсии

**Где изменилось:** `client/src/components/FilterPanel.jsx`, `server/src/routes/excursions.js`, `client/src/api.js`

**Что сделано:**
- Вместо стандартного `<input type="date">` — кастомный календарь
- Даты с доступными экскурсиями подсвечиваются фиолетовым фоном
- Выбранная дата — тёмно-фиолетовая
- Прошедшие даты недоступны для выбора
- Навигация по месяцам (стрелки влево/вправо)
- Легенда с пояснениями под календарём

**Зачем:** Визуально удобнее — пользователь сразу видит, на какие даты есть экскурсии.

---

## 7. Поиск экскурсий на главной странице

**Где изменилось:** `client/src/pages/Home.jsx`, `server/src/routes/excursions.js`

**Что сделано:**
- Поле ввода текста привязано к состоянию и работает
- Кнопка "Найти" передаёт запрос параметром `?search=...` в каталог
- Кнопки-категории ("Заводы", "Фабрики", "Лаборатории") перебрасывают на каталог с соответствующим поиском
- На сервере добавлен SQL-поиск по названию экскурсии, названию предприятия и описанию
- **Регистронезависимый поиск** — "ЗАВОД", "завод" и "Завод" находят одинаковые результаты (для кириллицы используется GLOB с классами символов `[Аа]`)

---

## 8. Поле поиска в панели фильтров каталога

**Где изменилось:** `client/src/components/FilterPanel.jsx`

**Что сделано:**
- Добавлено поле "Поиск" в панель фильтров слева
- Синхронизация с URL параметром `?search=`:
  - Ввод текста → обновляется URL
  - Изменение URL (например, переход с главной) → поле заполняется автоматически
- Кнопка "Сбросить фильтры" очищает и поисковый запрос

**Зачем:** Чтобы можно было искать экскурсии не только с главной, но и прямо в каталоге.

---

## 9. Параллакс-эффект на hero-секции

**Где изменилось:** `client/src/pages/Home.jsx`

**Что сделано:**
- Декоративные элементы (промышленные силуэты) при скролле двигаются медленнее основного контента (4-6% от скорости скролла) с лёгким уменьшением масштаба, создавая эффект глубины
- Основной контент (текст, поиск, кнопки) остаётся на месте

**Зачем:** Современный визуальный эффект, делает главную страницу более живой.

---

## 10. Реальная статистика на главной странице

**Где изменилось:** `client/src/pages/Home.jsx`, `server/src/routes/enterprises.js`, `client/src/api.js`

**Что сделано:**
- Вместо жёстко зашитых цифр теперь отображаются данные из базы данных:
  - Количество активных предприятий
  - Количество активных экскурсий
  - Количество зарегистрированных пользователей (роль "турист")
  - Средний рейтинг предприятий
- Добавлен API эндпоинт `GET /api/enterprises/stats/main`

**Зачем:** Статистика всегда актуальна и обновляется автоматически при добавлении новых данных.
