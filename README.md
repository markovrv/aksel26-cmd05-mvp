# ПромТур — Платформа промышленного туризма

Веб-приложение для организации и управления промышленным туризмом в Кировской области. Платформа соединяет туристов (B2C) с промышленными предприятиями, предлагающими экскурсии, сувенирную продукцию и интерактивные мастер-классы.

## Функциональные возможности

### Для туристов (B2C)
- Просмотр каталога предприятий и экскурсий с фильтрацией по городу, дате и поиску
- Детальная информация об экскурсии: описание, даты и время, стоимость, отзывы
- Выбор сувениров с возможностью персонализации (гравировка, имя, логотип)
- Бронирование экскурсий с выбором количества участников и временного слота
- Эмуляция оплаты с тремя сценариями (успех, ошибка, таймаут)
- Личный кабинет с историей бронирований и возможностью оставить отзыв
- Отмена бронирований

### Для предприятий (B2B)
- Панель управления заявками на экскурсии
- Управление экскурсиями: создание, редактирование, активация/деактивация
- Управление временными слотами
- Управление сувенирами и обработка заказов (подтверждение/отклонение)
- Отметка о проведении экскурсии
- Редактирование профиля предприятия

### Для администратора
- Создание и управление предприятиями
- Модерация отзывов (одобрение/отклонение)
- Полный доступ ко всем функциям платформы

### Для министерства (B2G)
- Аналитический дашборд с агрегированными данными:
  - Количество экскурсий и посетителей
  - Выручка с экскурсий и сувениров
  - Средний чек
  - Топ-5 предприятий по выручке
  - Динамика посещаемости по месяцам (12 месяцев)
  - Фильтрация по дате, городу, отрасли

## Быстрый старт

### Docker (рекомендуемый способ)

```bash
# Клонировать репозиторий
git clone <repo-url>
cd industry-tourism

# Настроить переменные окружения
cp server/.env.example server/.env

# Запустить контейнер
docker compose up -d --build
```

Приложение будет доступно по адресу: `http://localhost:27526`

### Локальный запуск

```bash
# Серверная часть
cd server
npm install
npm run seed      # Заполнить БД тестовыми данными
npm start         # Запустить сервер на порту 3000

# Клиентская часть (в отдельном терминале)
cd client
npm install
npm run dev       # Запустить dev-сервер на порту 5173
```

## API Endpoints

Все эндпоинты находятся под префиксом `/api`.

### Аутентификация
- `POST /api/auth/register` — регистрация нового пользователя
- `POST /api/auth/login` — вход, возвращает JWT
- `GET /api/auth/me` — информация о текущем пользователе

### Предприятия
- `GET /api/enterprises` — список активных предприятий (фильтры: город, поиск)
- `GET /api/enterprises/:id` — детальная информация о предприятии

### Экскурсии
- `GET /api/excursions` — список экскурсий (фильтры: город, дата, предприятие)
- `GET /api/excursions/:id` — детальная информация с слотами, сувенирами, отзывами

### Бронирования
- `POST /api/bookings` — создание брони
- `GET /api/bookings/my` — мои бронирования
- `GET /api/bookings/:id` — детали бронирования
- `PATCH /api/bookings/:id/cancel` — отмена бронирования

### Оплата
- `POST /api/payment/process` — эмуляция оплаты (сценарии: success, fail, timeout)

### Сувениры
- `GET /api/souvenirs/:enterprise_id` — список сувениров предприятия
- `POST /api/souvenir-orders` — создание заказа сувениров

### Отзывы
- `POST /api/reviews` — создание отзыва
- `GET /api/reviews/:enterprise_id` — опубликованные отзывы о предприятии

### Аналитика
- `GET /api/analytics/summary` — сводная аналитика для министерства/админа

### Заполнение базы данных

При первом запуске через Docker база данных заполняется автоматически. Для ручного заполнения:

```bash
cd server
npm run seed
```

Seed создаёт:
- 3 предприятия (завод, кондитерская фабрика, текстильная мануфактура)
- 6 экскурсий
- ~120 временных слотов на 30 дней
- 12 сувениров с опциями персонализации
- 5 пользователей (все роли)
- 3 тестовых бронирования
- 2 отзыва
- 3 уведомления

## Структура базы данных

- **users** — пользователи (BCrypt-хэш пароля, привязка к роли и предприятию)
- **enterprises** — предприятия (контакты, соцсети, сертификаты, фотографии)
- **excursions** — экскурсии (привязка к предприятию, ценообразование, лимиты)
- **slots** — временные слоты (время начала/окончания, цена, доступные места)
- **souvenirs** — сувениры (цена, остаток, опции персонализации)
- **bookings** — бронирования (статус: pending → paid → completed / cancelled)
- **souvenir_orders** — заказы сувениров (статус: pending → confirmed/rejected → ready_for_pickup → fulfilled)
- **reviews** — отзывы (рейтинг 1-5, модерация)
- **notifications** — уведомления пользователей
